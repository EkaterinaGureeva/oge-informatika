Задание 5 1 балл

Исполнитель Байтик умеет выполнять две команды, которым присвоены номера:

1. прибавить 13
2. извлечь квадратный корень

Составьте алгоритм, который преобразует число 81 в число 17, содержащий не более 5 команд. В ответе запишите только номера команд. Если таких алгоритмов более одного, запишите любой из них.

Дана программа на четырёх языках программирования.

Паскаль
var s, n, A: integer;
begin

  readln(n);
  if (s > 20) and (n = A)
    then writeln('ДА')
    else writeln('НЕТ');
end.
Python
s = int(input())
n = int(input())
if s > 20 and n == A:
    print('ДА')
else:
    print('НЕТ')
C++
#include <iostream>
using namespace std;
int main() {
  int s, n;
  cin >> s >> n;
  if (s > 20 && n == A)
    cout << "ДА";
  else
    cout << "НЕТ";
  return 0;
}
